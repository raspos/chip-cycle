# CHIP CYCLE — 한국 반도체 수출 20년의 기록 (2007.01~2026.09)

> **"반도체 수출액은 폭증했는데, 판매 개수는 줄었다"**  
> D램·플래시 메모리·복합구조칩 237개월 통관데이터(711개 관측치)와 한국은행 수출물가지수로 추적한 AI 시대 반도체 슈퍼사이클 인터랙티브 다큐멘터리

## 1. 프로젝트 개요

`chip-cycle`은 기존 `dram-cycle` 프로젝트의 코드·디자인·데이터 파이프라인을 보존하면서, **2007년 1월부터 2026년 9월까지 237개월(총 711개 관측치)**의 관세청·한국무역협회(K-stat) 3대 반도체 통관데이터 및 전체 반도체(`MTI 831`), 한국은행 경제통계시스템(ECOS) 수출물가지수(`4.3.1.3`), 한국은행 조사국 거시분석(`BOK 이슈노트 제2026-16호`, `제2026-20호`)을 통합한 블룸버그·FT 스타일 인터랙티브 데이터 저널리즘 웹사이트입니다.

## 3. 스토리라인 및 시각화 구성

- **ACT 01**: 반도체 수출액은 폭증했는데, 판매 개수는 줄었다 (2026년 9월 vs 2025년 9월 3품목 비교)
- **ACT 02 · 시각화 A**: 세 반도체의 20년 경쟁 (월별 수출액·신고수량·개당 평균 단가, 6대 역사적 국면 주석)
- **ACT 03 · 시각화 B**: 2025~2026년 단가 폭등 비교 (`2025.09=100` 지수화) 및 한국은행 수출물가지수(`2020=100`) 교차검증
- **ACT 04 · 시각화 C**: 수출 증가의 원인은 가격인가 수량인가 (Shapley 대칭 분해 및 산출 공식 전문 공개)
- **ACT 05 · 시각화 D**: 세 번의 슈퍼사이클(`2017–18`, `2021–22`, `2024–26`) 비교 및 정점 도달 순서 통계 검증
- **ACT 06**: 복합구조칩(`HSK 8542323000`) 심층 박스 — 통관 사실과 기술·산업적 해석의 엄격한 분리
- **ACT 07**: 한국 반도체 전체(`MTI 831`, 2026년 9월 `602.95억 달러`) 속의 3대 품목 구조
- **ACT 08**: 거시경제 파급경로 — 교역조건 개선(`GDI +13.2%` vs `GDP +3.8%`)과 낙수효과의 한계
- **ACT 09**: 6대 핵심 질문 Q&A 및 향후 리스크 시나리오 점검
- **APPENDIX**: 인터랙티브 데이터 랩(711개 관측치 검색·CSV 다운로드) 및 12대 데이터 무결성 검증 리포트

## 4. 실행 및 빌드 방법

```bash
# 개발 서버 실행
npm run dev

# 타입 체크
npx tsc --noEmit

# 프로덕션 빌드
npm run build
npm run start

# 데이터 파이프라인 재실행 (원본 K-stat .xls 및 BOK ECOS .csv -> JSON/CSV 변환 및 12개 항목 검증)
python scripts/build_chip_cycle_data.py
```
